# fake_imu + gyro_fft + matlab_csv_serial + logger 快速操作指南

## 🚀 一分钟快速启动

### 编译
```bash
make micoair_h743_default
# 上传固件
```

### 启动（NSH）
```bash
# 1. 启动数据源
fake_imu start

# 2. 启动 FFT 分析（会自动找到并切换到 fake_imu）
gyro_fft start

# 3. 启动串口输出
matlab_csv_serial start /dev/ttyS3

# 4. 启动日志记录
logger start -f -t

# 5. 运行 20 秒（2个完整扫频周期）

# 6. 停止
logger stop
matlab_csv_serial stop
gyro_fft stop
fake_imu stop
```

### PC 端接收串口数据
```python
import serial
ser = serial.Serial('/dev/ttyUSB0', 921600)
with open('imu_data.csv', 'w') as f:
    for _ in range(16000):  # 约 20 秒
        f.write(ser.readline().decode('utf-8'))
```

## 📊 数据分析

### 下载日志
```bash
# 从 SD 卡下载 .ulg 文件
# 路径：/fs/microsd/log/
```

### Python 分析脚本
```python
from pyulog import ULog
import matplotlib.pyplot as plt

log = ULog('log001.ulg')
fft = log.get_dataset('sensor_gyro_fft').data

time = (fft['timestamp'] - fft['timestamp'][0]) / 1e6
peak_z = fft['peak_frequencies_z'][:, 0]

plt.figure(figsize=(12, 6))
plt.plot(time, peak_z, '.-')
plt.xlabel('Time (s)')
plt.ylabel('Peak Frequency (Hz)')
plt.title('fake_imu Z-axis Chirp (0-1000 Hz)')
plt.grid(True)
plt.savefig('fft_analysis.png')
plt.show()
```

## 🔧 故障排查

### 问题：gyro_fft 还是用真实传感器

```bash
nsh> listener sensor_gyro_fft
device_id: 6684690  ← 不对！
```

**解决方案：重启 gyro_fft**
```bash
nsh> gyro_fft stop
nsh> gyro_fft start
INFO  [gyro_fft] fake_imu detected, switching to it for FFT analysis
```

**或者重启整个系统：**
```bash
nsh> reboot
# 重启后按顺序启动
```

### 问题：没有峰值（都是 nan）

```bash
peak_frequencies_z: [nan, nan, nan]
```

**检查参数：**
```bash
param show IMU_GYRO_FFT_EN   # 必须是 1
param show IMU_GYRO_FFT_SNR  # 降到 3-5

# 如果需要修改
param set IMU_GYRO_FFT_SNR 3
param save
reboot
```
