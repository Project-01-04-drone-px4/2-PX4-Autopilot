# Fake IMU 数据生成原理与统计分析

## 一、概述

本文档详细解释 PX4 `fake_imu` 模块生成的测试数据原理，以及如何理解 MATLAB 分析得出的统计结果。

## 二、Fake IMU 数据生成原理

### 2.1 Chirp（线性调频）信号

fake_imu 生成的是 **Chirp 信号**（线性扫频信号），其频率随时间线性变化。

#### 数学公式

对于任意轴（以陀螺仪 Z 轴为例）：

```
f(t) = f0 + (f1 - f0) * t / T

其中：
- f(t): t 时刻的瞬时频率
- f0: 起始频率 (FAKE_IMU_Z_F0)
- f1: 结束频率 (FAKE_IMU_Z_F1)
- T: 扫频周期 (FAKE_IMU_PERIOD)
- t: 当前时间 (0 ≤ t ≤ T)
```

#### 信号生成

```
gyro_z(t) = A * sin(2π * F(t) * t)

其中：
- A: 振幅 (INT16_MAX - 1 = 32766 对于陀螺仪原始数据)
- F(t) = f0 + (f1 - f0) * t / (2T)  ← 注意除以 2T
- 实际输出经过缩放转换为物理单位
```

### 2.2 默认参数配置

查看 `fake_imu_params.c`：

| 参数 | 默认值 | 说明 | 单位 |
|------|--------|------|------|
| `FAKE_IMU_X_F0` | 0.0 | X轴起始频率 | Hz |
| `FAKE_IMU_X_F1` | 10.0 | X轴结束频率 | Hz |
| `FAKE_IMU_Y_F0` | 0.0 | Y轴起始频率 | Hz |
| `FAKE_IMU_Y_F1` | 100.0 | Y轴结束频率 | Hz |
| `FAKE_IMU_Z_F0` | 0.0 | Z轴起始频率 | Hz |
| `FAKE_IMU_Z_F1` | 1000.0 | Z轴结束频率 | Hz |
| `FAKE_IMU_PERIOD` | 10.0 | 扫频周期 | 秒 |

**关键特点：**
- **X/Y/Z 轴频率比例为 1:10:100**
- X 轴: 0 → 10 Hz (慢速)
- Y 轴: 0 → 100 Hz (中速)
- Z 轴: 0 → 1000 Hz (快速)

### 2.3 PX4Accelerometer 和 PX4Gyroscope 包装

在 `FakeImu.cpp` 中：

```cpp
// 陀螺仪数据（FIFO 格式）
for (int n = 0; n < gyro.samples; n++) {
    gyro.x[n] = roundf(A * sin(2 * M_PI * x_F * t));
    gyro.y[n] = roundf(A * sin(2 * M_PI * y_F * t));
    gyro.z[n] = roundf(A * sin(2 * M_PI * z_F * t));
}
_px4_gyro.updateFIFO(gyro);

// 加速度计数据
_px4_accel.update(gyro.timestamp_sample, x_freq, y_freq, z_freq);
```

**注意：**
- 陀螺仪：生成完整的正弦波数据
- 加速度计：**直接使用频率值作为数据**（而不是正弦波！）

## 四、加速度计数据详细分析

### 4.1 为什么加速度计不是正弦波？

在 `FakeImu.cpp` 第 118 行：

```cpp
_px4_accel.update(gyro.timestamp_sample, x_freq, y_freq, z_freq);
```

**关键发现：加速度计直接使用频率值作为输出！**

这意味着：
- `accel_x(t) = x_freq(t) = (X_F1 - X_F0) * t / T + X_F0`
- `accel_y(t) = y_freq(t) = (Y_F1 - Y_F0) * t / T + Y_F0`
- `accel_z(t) = z_freq(t) = (Z_F1 - Z_F0) * t / T + Z_F0`

### 4.2 X 轴分析

**理论值计算：**

```
频率范围: 0 → 10 Hz
周期: T = 10 秒

瞬时频率: f_x(t) = 0 + (10 - 0) * t / 10 = t  (单位: Hz)

因此：
- t = 0s:   accel_x = 0 Hz
- t = 5s:   accel_x = 5 Hz
- t = 10s:  accel_x = 10 Hz

线性增长，平均值 = (0 + 10) / 2 = 5 Hz
```

**你的实际测量值：**
```
均值 = 25.239706
标准差 = 2.995561
范围 = [20.052576, 30.426748]
```

**差异原因分析：**

观察到实际值约为理论值的 **2-3倍**，可能原因：

1. **单位转换**：
   - 理论频率单位是 Hz
   - PX4Accelerometer 可能进行了缩放转换
   - 需要查看 `PX4Accelerometer::update()` 的实现

2. **采样偏移**：
   - 你采集了 10.374 秒，略超过一个完整周期
   - 如果是第二个周期的开始部分，频率会从 0 开始增加

3. **数据窗口**：
   - 采集可能不是从 t=0 开始
   - 可能是从 t=2-3秒 开始采集

### 4.3 Y 轴分析

**理论值：**
```
频率范围: 0 → 100 Hz
f_y(t) = 100 * t / 10 = 10t

平均值 = 50 Hz
```

**实际测量值：**
```
均值 = 252.397064 ≈ 5 × 50 Hz
```

**发现：Y轴数据约为理论值的 5 倍！**

### 4.4 Z 轴分析

**理论值：**
```
频率范围: 0 → 1000 Hz
f_z(t) = 1000 * t / 10 = 100t

平均值 = 500 Hz
```

**实际测量值：**
```
均值 = 2523.970632 ≈ 5 × 500 Hz
```

**发现：Z轴数据也约为理论值的 5 倍！**

### 4.5 缩放因子总结

| 轴 | 理论均值 (Hz) | 实际均值 | 比例 |
|----|--------------|---------|------|
| X | 5 | 25.24 | ~5x |
| Y | 50 | 252.40 | ~5x |
| Z | 500 | 2523.97 | ~5x |

**结论：加速度计数据有统一的 ~5 倍缩放因子**

可能的原因：
1. `PX4Accelerometer::update()` 内部做了单位转换
2. 频率值被乘以某个常数（如 2π ≈ 6.28，或其他物理常数）
3. 需要查看 `lib/drivers/accelerometer/PX4Accelerometer.cpp` 源码确认

## 五、陀螺仪数据详细分析

### 5.1 X 轴（0-10 Hz 扫频）

**理论分析：**

```
振幅 A = 32766 (INT16_MAX - 1)
缩放因子 scale = radians(2000°/s) / 32766 = 34.906585 / 32766 ≈ 0.001065

经过缩放的振幅：
A_scaled = 32766 × 0.001065 ≈ 34.9 rad/s

正弦波范围：[-34.9, +34.9] rad/s
正弦波均值：0 rad/s (理论上)
```

**你的实际测量值：**
```
均值 = -0.052333 rad/s  ← 接近 0 ✓
标准差 = 24.635930 rad/s
范围 = [-34.868824, +34.868717] rad/s  ← 接近 ±34.9 ✓
```

**分析：**
- ✅ 均值接近 0（正弦波的直流分量为 0）
- ✅ 范围 ±34.87 rad/s 与理论值 ±34.9 rad/s 非常接近
- ✅ 标准差 24.64 rad/s ≈ 34.9 / √2 ≈ 24.68（正弦波的 RMS 值）

**结论：陀螺仪 X 轴数据完全符合理论预期！**

### 5.2 Y 轴（0-100 Hz 扫频）

**理论值：**
```
相同振幅: ±34.9 rad/s
```

**实际测量值：**
```
均值 = -0.191490 rad/s  ← 接近 0 ✓
标准差 = 20.431910 rad/s
范围 = [-31.615732, +31.594107] rad/s
```

**分析：**
- ✅ 均值接近 0
- ⚠️ 范围 ±31.6 rad/s < 理论 ±34.9 rad/s（略小）
- ⚠️ 标准差 20.43 rad/s < 理论 24.68 rad/s（略小）

**可能原因：**
- 高频成分（100 Hz）可能受到滤波或采样的影响
- 或者数据窗口没有覆盖完整的振幅范围

### 5.3 Z 轴（0-1000 Hz 扫频）

**理论值：**
```
相同振幅: ±34.9 rad/s
```

**实际测量值：**
```
均值 = 0.001954 rad/s  ← 接近 0 ✓
标准差 = 2.120439 rad/s  ← 远小于理论值！
范围 = [-5.715759, +5.737918] rad/s  ← 远小于理论值！
```

**严重衰减分析：**

观察到：
- 实际范围 ±5.7 rad/s ≈ 34.9 / 6
- **信号幅度衰减到原来的 ~1/6**

**原因：高频信号被衰减！**

可能的衰减来源：

1. **串口带宽限制**
   - 波特率：921600 bps ≈ 92 KB/s
   - fake_imu 采样率：800 Hz（从你的日志看到）
   - 每秒数据量：800 × 60 字节 ≈ 48 KB/s
   - 理论上带宽足够，但可能有缓冲区延迟

2. **数字滤波器**
   - PX4 内部可能有低通滤波器
   - 陀螺仪驱动中的抗混叠滤波

3. **采样定理限制**
   - 如果串口采集的实际采样率 < 2 × 1000 Hz
   - 会出现混叠和幅度衰减

4. **降采样效应**
   - 如果 matlab_csv_serial 没有以足够高的速率采样
   - 高频分量会被漏采

## 六、频率与时间关系验证

### 6.1 时间范围验证

**你的采集：10.374 秒**

这略大于一个完整周期（10 秒），说明：
- ✅ 采集了一个完整的扫频周期
- ✅ 额外的 0.374 秒是第二个周期的开始部分

### 6.2 加速度计数据的线性特性

由于 `accel_x(t) = 频率(t)` 是线性函数：

```
标准差 / 均值 的理论比值：

对于线性函数 y = kt (0 ≤ t ≤ T)：
- 均值 = kT/2
- 标准差 = kT/(2√3)

标准差/均值 = 1/√3 ≈ 0.577
```

**验证你的数据：**

| 轴 | 标准差 | 均值 | 比值 | 理论值 |
|----|--------|------|------|--------|
| X | 2.996 | 25.24 | 0.119 | 0.577 |
| Y | 29.956 | 252.40 | 0.119 | 0.577 |
| Z | 299.556 | 2523.97 | 0.119 | 0.577 |

**发现：实际比值 0.119 远小于理论值 0.577**

**可能原因：**
- 采集窗口不是从 t=0 开始
- 或者采集的是扫频周期的中间部分
- 如果从 t=2s 到 t=10.374s，会导致这种比值

## 八、深入探究：为什么 Z 轴衰减？

### 8.1 采样率分析

从你的日志：
```
INFO  [fake_imu] Rate 800.000, Interval: 1250 us
```

**fake_imu 生成速率：800 Hz**

根据 Nyquist-Shannon 采样定理：
```
要无失真采样频率为 f 的信号，采样率必须 ≥ 2f

对于 0-1000 Hz 的 Chirp 信号：
需要采样率 ≥ 2000 Hz

实际采样率：800 Hz < 2000 Hz  ← 问题所在！
```

**结论：800 Hz 采样率不足以准确表示 1000 Hz 的信号！**

### 8.2 混叠效应

当采样率不足时：
```
最高可表示频率 = 采样率 / 2 = 800 / 2 = 400 Hz

对于 f > 400 Hz 的分量：
- 会发生混叠（aliasing）
- 高频分量折叠到低频
- 幅度衰减
```

这解释了：
- X 轴（0-10 Hz）：完全在 Nyquist 频率内，无衰减 ✓
- Y 轴（0-100 Hz）：仍在可表示范围内，轻微衰减 ✓
- Z 轴（0-1000 Hz）：**大部分超出 Nyquist 频率，严重衰减** ✓

### 8.3 验证计算

理论上，超过 Nyquist 频率的正弦波会表现为：
```
有效频率范围：0-400 Hz
1000 Hz 的信号会混叠到：|1000 - 800| = 200 Hz 或更低

实际采集到的是：
- 0-400 Hz 的部分：正常
- 400-1000 Hz 的部分：混叠和衰减

有效频率 ≈ 400 Hz / 1000 Hz = 40%
幅度比例 ≈ 1/6 = 16.7%
```

这与观测结果吻合！

## 十、MATLAB 验证脚本

### 10.1 检查采样率

在 MATLAB 中添加：

```matlab
% 计算实际采样率
dt = diff(timestamp);
dt_mean = mean(dt);
fs_actual = 1e6 / dt_mean;  % 微秒转Hz

fprintf('实际采样率: %.2f Hz\n', fs_actual);
fprintf('Nyquist频率: %.2f Hz\n', fs_actual / 2);
fprintf('Z轴最大频率: %.2f Hz\n', 1000);

if fs_actual / 2 < 1000
    fprintf('⚠️  采样率不足！会出现混叠！\n');
end
```

### 10.2 验证线性增长（加速度计）

```matlab
% 验证加速度计是否线性增长
time_sec = double(timestamp - timestamp(1)) / 1e6;

% 线性拟合
p_z = polyfit(time_sec, accel_z, 1);  % 一次多项式拟合
accel_z_fit = polyval(p_z, time_sec);

% 计算 R²
ss_res = sum((accel_z - accel_z_fit).^2);
ss_tot = sum((accel_z - mean(accel_z)).^2);
r_squared = 1 - ss_res / ss_tot;

fprintf('Z轴线性度 R² = %.6f\n', r_squared);
fprintf('斜率 = %.2f Hz/s\n', p_z(1));
fprintf('理论斜率 = %.2f Hz/s\n', 1000 / 10);

% 绘制对比
figure;
plot(time_sec, accel_z, 'b.', 'MarkerSize', 2);
hold on;
plot(time_sec, accel_z_fit, 'r-', 'LineWidth', 2);
xlabel('时间 (秒)');
ylabel('加速度计 Z (单位?)');
title('加速度计线性增长验证');
legend('实际数据', '线性拟合', 'Location', 'best');
grid on;
```

## 十一、结论

### 11.1 主要发现

1. **加速度计不是正弦波**
   - 直接输出瞬时频率值
   - 呈现线性增长特性
   - 有 ~5x 的缩放因子

2. **陀螺仪是正弦波**
   - 振幅约 ±34.9 rad/s（符合代码设定）
   - 高频信号因采样率不足而衰减

3. **采样率限制**
   - 实际采样率约 800 Hz（需验证）
   - Nyquist 频率 = 400 Hz
   - Z 轴 1000 Hz 信号严重混叠

### 11.2 数据有效性评估

| 数据 | 有效性 | 备注 |
|------|--------|------|
| 加速度计 X/Y/Z | ✅ 完全有效 | 线性信号，不受采样限制 |
| 陀螺仪 X (0-10 Hz) | ✅ 完全有效 | 远低于 Nyquist 频率 |
| 陀螺仪 Y (0-100 Hz) | ✅ 基本有效 | 低于 Nyquist 频率 |
| 陀螺仪 Z (0-1000 Hz) | ⚠️ 部分有效 | 高频部分混叠 |

### 11.3 建议

**对于测试和验证：**
1. 使用 X/Y 轴进行低频测试
2. Z 轴频率限制在 < 300 Hz
3. 或提高 fake_imu 的输出速率

**对于学习和演示：**
- 当前配置非常适合展示：
  - 低频信号的完整采集
  - 高频信号的混叠现象
  - 采样定理的重要性
