## 四、优先级说明

| 优先级 | 任务 | 原因 |
|--------|------|------|
| **5 (最高)** | imu_task | • 传感器数据采集最关键<br>• 数据丢失无法恢复<br>• 需要低延迟 |
| **6** | angular_velocity_task | • 内环控制依赖<br>• 需要实时滤波数据 |
| **7** | control_task | • 控制回路实时性要求高<br>• 直接影响飞行稳定性 |
| **8** | imu_process_task | • 为EKF提供数据<br>• 相对不紧急 |
| **10** | estimator_task | • 姿态估计有一定延迟容忍<br>• 计算量大，优先级适当降低 |

**注意**：RT-Thread优先级数字越小优先级越高（0最高）

## 八、初始化顺序

```c
main() {
    // 1. 硬件初始化
    board_init();
    spi_init();
    pwm_init();

    // 2. uORB初始化
    orb_init();

    // 3. 创建任务（按优先级从低到高）
    rt_thread_create("estimator",  ..., prio=10);  // 先创建
    rt_thread_create("imu_proc",   ..., prio=8);
    rt_thread_create("control",    ..., prio=7);
    rt_thread_create("ang_vel",    ..., prio=6);
    rt_thread_create("imu",        ..., prio=5);   // 后创建（最高优先级）

    // 4. 启动所有任务
    rt_thread_startup(...);
}
```
