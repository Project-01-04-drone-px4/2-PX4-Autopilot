# 快速开始 - PX4配置修改清单

## 概述

本文档总结了为移植PX4核心飞控信号链到RT-Thread而对MicoAir H743飞控板所做的配置修改。

---

## 已完成的配置修改

### ✅ 1. 板级配置 - 只启用BMI270

**文件**: `boards/micoair/h743/default.px4board`

**修改位置**: 第13-15行

**修改内容**:
```ini
# 移植修改：只使用BMI270作为唯一IMU
# CONFIG_DRIVERS_IMU_BOSCH_BMI088 is not set
CONFIG_DRIVERS_IMU_BOSCH_BMI270=y
```

**说明**:
- 禁用BMI088驱动，减少代码体积
- 只编译BMI270驱动

---

### ✅ 2. 参数配置 - EKF2单例模式 + PWM输出

**文件**: `boards/micoair/h743/init/rc.board_defaults`

#### 2.1 PWM模式配置（第12-13行）
```bash
# 移植修改：使用PWM代替DShot
param set-default PWM_MAIN_TIM0 400     # PWM 400Hz (原来是-4 DShot300)
```

#### 2.2 EKF2单例模式（第27-36行）
```bash
# ============ 移植配置：EKF2单例模式 + 仅BMI270 ============
# EKF2单例模式配置
param set-default SENS_IMU_MODE 1        # 单实例模式（由Sensors模块选择IMU）
param set-default EKF2_MULTI_IMU 0       # 禁用EKF2多实例
param set-default EKF2_MULTI_MAG 0       # 禁用多磁力计EKF2

# 传感器选择：强制选择BMI270（假设为Instance 0）
# 如果BMI270是Instance 1，则设置为1
param set-default SENS_IMU_PRIME 0      # 选择第一个IMU
```

#### 2.3 PWM电机输出功能映射（第38-43行）
```bash
# PWM电机输出配置（400Hz PWM）
param set-default PWM_MAIN_FUNC1 101    # 电机1
param set-default PWM_MAIN_FUNC2 102    # 电机2
param set-default PWM_MAIN_FUNC3 103    # 电机3
param set-default PWM_MAIN_FUNC4 104    # 电机4
```

## 信号链数据流验证

### 完整信号链
```
BMI270 → sensor_gyro_fifo → VehicleIMU → vehicle_imu → EKF2 → vehicle_attitude
                          ↘ VehicleAngularVelocity → vehicle_angular_velocity
                                                    ↓
                                                mc_rate_control
                                                    ↓
                                              control_allocator
                                                    ↓
                                                  PWMOut
                                                    ↓
                                                  [电机]
```

### 逐级验证命令

```bash
# 1. BMI270 FIFO输出
nsh> listener sensor_gyro_fifo
# 应该看到800Hz的数据

# 2. VehicleIMU输出
nsh> listener vehicle_imu
# 应该看到~265Hz的积分数据

# 3. VehicleAngularVelocity输出
nsh> listener vehicle_angular_velocity
# 应该看到~667Hz的滤波后角速度

# 4. EKF2姿态输出
nsh> listener vehicle_attitude
# 应该看到~193Hz的姿态四元数

# 5. 角速率设定值
nsh> listener vehicle_rates_setpoint
# 应该看到遥控器输入对应的角速率

# 6. 力矩输出
nsh> listener vehicle_torque_setpoint
# 应该看到PID控制器输出

# 7. 电机输出
nsh> listener actuator_motors
# 应该看到混控后的4个电机归一化输出 [-1, 1]
```

## 参数调整建议（可选）

### 如果姿态不稳定

```bash
# 降低姿态控制增益
param set MC_ROLL_P 5.0   # 默认6.5
param set MC_PITCH_P 5.0  # 默认6.5

# 降低角速率控制增益
param set MC_ROLLRATE_P 0.12   # 默认0.15
param set MC_PITCHRATE_P 0.12  # 默认0.15
```

### 如果需要更高的PWM频率

```bash
# 修改为1000Hz PWM（某些电调支持）
param set PWM_MAIN_TIM0 1000
# 重启后生效
reboot
```

### 如果BMI270是Instance 1而非Instance 0

```bash
# 修改传感器选择
param set SENS_IMU_PRIME 1
# 重启后生效
reboot
```

## 常见问题

### Q1: 编译后固件大小是否减小？

**A**: 是的，禁用BMI088后会减少约50-80KB Flash。

### Q2: 如何确认使用的是单EKF2实例？

**A**:
```bash
nsh> work_queue status | grep ekf2
# 应该只看到1行ekf2，而不是2行
```

### Q3: PWM频率400Hz够用吗？

**A**:
- 常规飞行：400Hz足够
- 竞速穿越：建议1000Hz或DShot
- 航拍平稳：200Hz即可

### Q4: 如何验证BMI270正常工作？

**A**:
```bash
nsh> sensors status
# 查看IMU状态

nsh> listener sensor_gyro_fifo 0
# 应该看到实时数据流

# 静止时陀螺数据应接近0
# 移动飞控应看到对应变化
```

## 故障排除

### 问题1：编译失败 - BMI270驱动未找到

**解决**:
```bash
# 清理编译缓存
make distclean
make micoair_h743_default
```

### 问题2：启动后没有IMU数据

**检查**:
```bash
nsh> dmesg | grep -i bmi
nsh> bmi270 status
# 检查SPI总线是否正常
nsh> spi_test bus SPI1
```

### 问题3：EKF2不收敛

**调整参数**:
```bash
param set EKF2_GBIAS_INIT 0.1  # 增大初始陀螺偏差
param set EKF2_ABL_LIM 0.4     # 增大偏差学习限制
param save
reboot
```
