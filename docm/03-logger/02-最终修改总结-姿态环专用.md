## 四、bodyzToAttitude 转换详解

### 函数原型

```cpp
void bodyzToAttitude(Vector3f body_z, const float yaw_sp, vehicle_attitude_setpoint_s &att_sp)
```

### 输入参数

| 参数      | 类型              | 说明                                  |
|-----------|-------------------|---------------------------------------|
| `body_z`  | `Vector3f`        | 期望的机体 Z 轴方向（推力方向）        |
| `yaw_sp`  | `float`           | 期望的偏航角 (rad)                    |
| `att_sp`  | 引用              | 输出的姿态设定值（填充 `q_d` 四元数） |

### 核心逻辑

这个函数的作用是：**从期望的推力方向和偏航角，反推出期望的姿态（四元数）**。

#### 步骤 1: 归一化期望的机体 Z 轴

```cpp
// zero vector, no direction, set safe level value
if (body_z.norm_squared() < FLT_EPSILON) {
    body_z(2) = 1.f;  // 默认指向上方
}
body_z.normalize();  // 归一化为单位向量
```

**说明**:
- `body_z` 是期望的推力方向（机体坐标系的 Z 轴）
- 在多旋翼中，推力方向就是机体 Z 轴的负方向
- 归一化后，`body_z` 成为单位向量

#### 步骤 2: 计算期望的机体 X 轴

```cpp
// vector of desired yaw direction in XY plane, rotated by PI/2
const Vector3f y_C{-sinf(yaw_sp), cosf(yaw_sp), 0.f};

// desired body_x axis, orthogonal to body_z
Vector3f body_x = y_C % body_z;  // 叉乘

// keep nose to front while inverted upside down
if (body_z(2) < 0.f) {
    body_x = -body_x;  // 倒飞时反向
}
```

**说明**:
- `y_C` 是与期望偏航角垂直的向量（在 NED 坐标系的 XY 平面）
- 通过叉乘 `y_C × body_z` 得到期望的机体 X 轴
- 确保机体 X 轴（机头方向）与偏航角一致

**数学原理**:
- 偏航角 `yaw_sp` 定义了机头在 XY 平面的朝向
- `y_C` 是偏航方向旋转 90° 的向量
- `body_x` 必须与 `body_z` 垂直，且在偏航方向上

#### 步骤 3: 计算期望的机体 Y 轴

```cpp
body_x.normalize();

// desired body_y axis
const Vector3f body_y = body_z % body_x;  // 叉乘
```

**说明**:
- 通过叉乘 `body_z × body_x` 得到机体 Y 轴
- 确保三个轴互相垂直，构成右手坐标系

#### 步骤 4: 构造旋转矩阵并转换为四元数

```cpp
Dcmf R_sp;

// fill rotation matrix
for (int i = 0; i < 3; i++) {
    R_sp(i, 0) = body_x(i);
    R_sp(i, 1) = body_y(i);
    R_sp(i, 2) = body_z(i);
}

// copy quaternion setpoint to attitude setpoint topic
const Quatf q_sp{R_sp};
q_sp.copyTo(att_sp.q_d);
```

**说明**:
- 将三个机体轴组成旋转矩阵（DCM, Direction Cosine Matrix）
- 从旋转矩阵转换为四元数
- 填充到姿态设定值消息中

### 应用场景

这个函数主要用于**位置控制模式**:

1. **位置控制器**计算出期望的加速度 `a_sp`
2. 加速度转换为期望的推力 `thr_sp = m * (a_sp - g)`
3. 推力方向就是期望的机体 Z 轴方向 `body_z = -thr_sp / ||thr_sp||`
4. 调用 `bodyzToAttitude(body_z, yaw_sp, att_sp)` 得到姿态设定值

### 为什么撤回这个修改？

因为你**主要飞姿态环**（Manual/Stabilized 模式），不经过位置控制器：

- **姿态环**: 遥控器 → `mc_att_control` → `vehicle_attitude_setpoint` ✓（已修改）
- **位置环**: 航点 → `mc_pos_control` → `bodyzToAttitude` → `vehicle_attitude_setpoint` ✗（已撤回）

等你将来需要飞位置环（Position/Auto 模式）时，可以再添加这部分修改。

## 八、数据分析示例

### 外环（姿态环）性能分析

```python
import numpy as np
import matplotlib.pyplot as plt
from pyulog import ULog

ulog = ULog('log.ulg')

# 提取数据
attitude_sp = ulog.get_dataset('vehicle_attitude_setpoint').data
attitude = ulog.get_dataset('vehicle_attitude').data

# 时间对齐
import pandas as pd
time_base = attitude_sp['timestamp'] * 1e-6  # 转换为秒

df = pd.DataFrame({
    'time': time_base,
    'roll_sp': np.rad2deg(attitude_sp['roll_body']),  # ✨ 直接读取欧拉角
    'roll_act': np.rad2deg(np.interp(
        time_base,
        attitude['timestamp'] * 1e-6,
        attitude['roll']  # ✨ 直接读取欧拉角
    ))
})

# 计算误差
df['roll_error'] = df['roll_sp'] - df['roll_act']

# 绘图
fig, axes = plt.subplots(2, 1, figsize=(12, 8), sharex=True)

# 子图1: 期望 vs 实际
axes[0].plot(df['time'], df['roll_sp'], label='Setpoint', linewidth=2)
axes[0].plot(df['time'], df['roll_act'], label='Actual', linewidth=1)
axes[0].set_ylabel('Roll Angle (deg)')
axes[0].legend()
axes[0].grid(True)
axes[0].set_title('Outer Loop: Attitude Tracking (Multicopter Attitude Mode)')

# 子图2: 跟踪误差
axes[1].plot(df['time'], df['roll_error'], color='red', linewidth=1)
axes[1].axhline(0, color='black', linestyle='--', linewidth=0.5)
axes[1].set_ylabel('Roll Error (deg)')
axes[1].set_xlabel('Time (s)')
axes[1].grid(True)

plt.tight_layout()
plt.show()

# 性能指标
print("外环姿态跟踪性能:")
print(f"  平均误差: {np.mean(df['roll_error']):.3f} deg")
print(f"  标准差:   {np.std(df['roll_error']):.3f} deg")
print(f"  最大误差: {np.max(np.abs(df['roll_error'])):.3f} deg")
```
