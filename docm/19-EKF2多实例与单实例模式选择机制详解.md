# 19-EKF2多实例与单实例模式选择机制详解
## 基于MicoAir H743飞控的EKF2模式分析

---

## 1. 概述

本文档详细分析PX4 EKF2模块的**多实例模式（Multi-Instance Mode）**和**单实例模式（Single-Instance Mode）**的选择机制、工作原理和差异。以MicoAir H743飞控（配备BMI088和BMI270双IMU）为例，说明如何确定当前使用的模式。

### 核心问题
1. MicoAir H743使用的是多实例还是单实例模式？
2. 模式选择的决定因素是什么（参数还是硬编码）？
3. 多实例和单实例模式有什么区别？
4. 核心代码位置在哪里？

---

## 2. 模式选择的决定因素

### 2.1 关键参数

EKF2的模式选择**完全由参数决定**，没有硬编码。涉及两个关键参数：

| 参数名 | 默认值 | 作用 | 定义位置 |
|--------|--------|------|---------|
| **SENS_IMU_MODE** | 1 | 传感器选择模式 | `src/modules/sensors/sensor_params.c:246` |
| **EKF2_MULTI_IMU** | 0 | 多EKF的IMU数量 | `src/modules/ekf2/params_multi.yaml:5` |
| **EKF2_MULTI_MAG** | 0 | 多EKF的磁力计数量 | `src/modules/ekf2/params_multi.yaml:15` |

### 2.2 SENS_IMU_MODE 参数定义

**文件**: `src/modules/sensors/sensor_params.c`

**第246行**: SENS_IMU_MODE默认值
```c
PARAM_DEFINE_INT32(SENS_IMU_MODE, 1);
```

**参数说明**：
- **SENS_IMU_MODE = 1**（默认）：单实例模式
  - Sensors模块进行IMU选择
  - 发布`sensor_combined`
  - EKF2订阅`sensor_combined`

- **SENS_IMU_MODE = 0**：多实例模式
  - Sensors模块不进行选择
  - 每个IMU发布独立的`vehicle_imu`
  - 每个IMU对应一个EKF2实例
  - EKF2Selector选择最优EKF输出

### 2.3 EKF2_MULTI_IMU 参数定义

**文件**: `src/modules/ekf2/params_multi.yaml`

**第5-14行**: EKF2_MULTI_IMU参数
```yaml
EKF2_MULTI_IMU:
  description:
    short: Multi-EKF IMUs
    long: Maximum number of IMUs to use for Multi-EKF. Set 0 to disable. Requires
      SENS_IMU_MODE 0.
  type: int32
  default: 0
  reboot_required: true
  min: 0
  max: 4
```

**参数说明**：
- **EKF2_MULTI_IMU = 0**（默认）：禁用多实例模式
- **EKF2_MULTI_IMU = 1**：只使用第一个IMU（实际是单实例）
- **EKF2_MULTI_IMU = 2**：使用2个IMU，创建2个EKF2实例
- **EKF2_MULTI_IMU = 3-4**：使用3-4个IMU

## 3. 模式选择的核心代码

### 3.1 EKF2启动时的模式判断

**文件**: `src/modules/ekf2/EKF2.cpp`

**第2773-2839行**: task_spawn函数（EKF2启动入口）
```cpp
int EKF2::task_spawn(int argc, char *argv[])
{
    bool success = false;
    bool replay_mode = false;

    // ... replay模式检查 ...

#if defined(CONFIG_EKF2_MULTI_INSTANCE)
    bool multi_mode = false;           // ← 模式标志
    int32_t imu_instances = 0;
    int32_t mag_instances = 0;

    // ========== 核心判断逻辑 ==========
    int32_t sens_imu_mode = 1;
    param_get(param_find("SENS_IMU_MODE"), &sens_imu_mode);  // ← 读取参数

    if (sens_imu_mode == 0) {                                 // ← 关键判断！
        // ekf selector requires SENS_IMU_MODE = 0
        multi_mode = true;                                    // ← 启用多实例模式

        // IMUs (1 - MAX_NUM_IMUS supported)
        param_get(param_find("EKF2_MULTI_IMU"), &imu_instances);  // ← 读取IMU数量

        if (imu_instances < 1 || imu_instances > MAX_NUM_IMUS) {
            // 限制在1-4之间
            imu_instances = math::constrain(imu_instances, 1, MAX_NUM_IMUS);
        }

        // 同样读取磁力计数量
        param_get(param_find("EKF2_MULTI_MAG"), &mag_instances);
    }
#endif

    // ... 后续启动逻辑 ...
}
```

**核心逻辑**：
```
IF (SENS_IMU_MODE == 0) THEN
    multi_mode = true
    读取 EKF2_MULTI_IMU 和 EKF2_MULTI_MAG
    启动多个EKF2实例 + EKF2Selector
ELSE
    multi_mode = false
    启动单个EKF2实例
END IF
```

### 3.2 模式选择流程图

```
系统启动
  ↓
ekf2 start 命令
  ↓
EKF2::task_spawn()
  ↓
读取 param_find("SENS_IMU_MODE")
  ↓
┌─────────────────┬─────────────────┐
│                 │                 │
│ SENS_IMU_MODE=0 │ SENS_IMU_MODE=1 │
│                 │                 │
↓                 ↓                 ↓
多实例模式        单实例模式
│                                   │
├─ 读取 EKF2_MULTI_IMU             ├─ 创建1个EKF2实例
├─ 读取 EKF2_MULTI_MAG             ├─ 订阅 sensor_combined
├─ 创建 EKF2Selector               └─ 发布 vehicle_attitude
├─ 创建 N 个 EKF2实例
│  (N = IMU数 × MAG数)
├─ 每个实例订阅独立的 vehicle_imu
└─ EKF2Selector选择最优并发布
```

## 4. MicoAir H743的实际配置

### 4.1 硬件配置

**文件**: `boards/micoair/h743/default.px4board`

**第27-28行**: 双IMU配置
```config
CONFIG_DRIVERS_IMU_BOSCH_BMI088=y
CONFIG_DRIVERS_IMU_BOSCH_BMI270=y
```

**硬件**：
- IMU 0: BMI088（Instance 0）
- IMU 1: BMI270（Instance 1）

### 4.2 默认参数配置

**文件**: `boards/micoair/h743/init/rc.board_defaults`

**未设置EKF2相关参数**，使用系统默认值：
- SENS_IMU_MODE = 1（默认）
- EKF2_MULTI_IMU = 0（默认）

### 4.3 结论：MicoAir H743默认使用**单实例模式**

**推理过程**：
```
1. SENS_IMU_MODE = 1 (默认值，未在rc.board_defaults中修改)
2. EKF2::task_spawn() 中判断: sens_imu_mode == 0 ?
   → 否 (sens_imu_mode = 1)
3. 结果: multi_mode = false
4. 启动单个EKF2实例
```

**数据流**：
```
BMI088 → sensor_gyro/accel Instance 0
BMI270 → sensor_gyro/accel Instance 1
    ↓
VehicleIMU Instance 0 → vehicle_imu Instance 0
VehicleIMU Instance 1 → vehicle_imu Instance 1
    ↓
Sensors::VotedSensorsUpdate (投票选择最优IMU)
    ↓
sensor_combined (融合后的单一数据源)
    ↓
EKF2 (单实例) 订阅 sensor_combined
    ↓
vehicle_attitude, vehicle_local_position, ... (直接发布)
```

### 4.4 如何切换到多实例模式？

如果想启用多实例模式，需要修改参数：

```bash
# 通过QGroundControl或NSH命令行
param set SENS_IMU_MODE 0      # 关键！必须设为0
param set EKF2_MULTI_IMU 2     # 使用2个IMU
param set EKF2_MULTI_MAG 1     # 使用1个磁力计（如果有）
reboot                         # 重启生效
```

或在`rc.board_defaults`中添加：
```bash
param set-default SENS_IMU_MODE 0
param set-default EKF2_MULTI_IMU 2
```

## 5. 多实例模式的启动流程

### 5.1 多实例模式的创建代码

**文件**: `src/modules/ekf2/EKF2.cpp`

**第2841-2923行**: 多实例模式启动
```cpp
if (multi_mode && !replay_mode) {
    // Start EKF2Selector if it's not already running
    if (_ekf2_selector.load() == nullptr) {
        EKF2Selector *inst = new EKF2Selector();  // ← 创建选择器

        if (inst) {
            _ekf2_selector.store(inst);
        } else {
            PX4_ERR("Failed to create EKF2 selector");
            return PX4_ERROR;
        }
    }

    const hrt_abstime time_started = hrt_absolute_time();
    const int multi_instances = math::min(imu_instances * mag_instances,
                                          static_cast<int32_t>(EKF2_MAX_INSTANCES));
    int multi_instances_allocated = 0;

    // 为每个 IMU × MAG 组合创建EKF2实例
    bool ekf2_instance_created[MAX_NUM_IMUS][MAX_NUM_MAGS] {};

    while ((multi_instances_allocated < multi_instances) && ...) {
        for (uint8_t mag = 0; mag < mag_instances; mag++) {
            for (uint8_t imu = 0; imu < imu_instances; imu++) {

                uORB::SubscriptionData<vehicle_imu_s> vehicle_imu_sub{ORB_ID(vehicle_imu), imu};

                // 检查IMU和MAG数据是否可用
                if ((vehicle_mag_sub.advertised() || mag == 0) &&
                    (vehicle_imu_sub.advertised())) {

                    if (!ekf2_instance_created[imu][mag]) {
                        // 创建EKF2实例，传入 multi_mode=true
                        EKF2 *ekf2_inst = new EKF2(true, px4::ins_instance_to_wq(imu), false);

                        if (ekf2_inst && ekf2_inst->multi_init(imu, mag)) {
                            int actual_instance = ekf2_inst->instance();
                            _objects[actual_instance].store(ekf2_inst);
                            success = true;
                            multi_instances_allocated++;
                            ekf2_instance_created[imu][mag] = true;

                            PX4_DEBUG("starting instance %d, IMU:%d, MAG:%d",
                                     actual_instance, imu, mag);

                            _ekf2_selector.load()->ScheduleNow();
                        }
                    }
                }
            }
        }
    }
}
```

**关键点**：
- 实例数量 = IMU数量 × MAG数量（最多4个）
- 每个实例订阅特定的`vehicle_imu`实例
- 创建EKF2Selector进行选择

## 6. 多实例 vs 单实例的核心区别

### 6.1 构造函数差异

**文件**: `src/modules/ekf2/EKF2.cpp`

**第52-64行**: EKF2构造函数
```cpp
EKF2::EKF2(bool multi_mode, const px4::wq_config_t &config, bool replay_mode):
    ModuleParams(nullptr),
    ScheduledWorkItem(MODULE_NAME, config),
    _replay_mode(replay_mode && !multi_mode),
    _multi_mode(multi_mode),
    _instance(multi_mode ? -1 : 0),

    // ========== 关键差异：发布的主题不同 ==========
    _attitude_pub(multi_mode ? ORB_ID(estimator_attitude) : ORB_ID(vehicle_attitude)),
    _local_position_pub(multi_mode ? ORB_ID(estimator_local_position) : ORB_ID(vehicle_local_position)),
    _global_position_pub(multi_mode ? ORB_ID(estimator_global_position) : ORB_ID(vehicle_global_position)),
    _odometry_pub(multi_mode ? ORB_ID(estimator_odometry) : ORB_ID(vehicle_odometry)),
#if defined(CONFIG_EKF2_WIND)
    _wind_pub(multi_mode ? ORB_ID(estimator_wind) : ORB_ID(wind)),
#endif
    // ...
```

**差异总结**：

| 特性 | 单实例模式 (multi_mode=false) | 多实例模式 (multi_mode=true) |
|------|------------------------------|----------------------------|
| **订阅主题** | `sensor_combined` | `vehicle_imu` (特定实例) |
| **发布主题** | `vehicle_attitude`<br>`vehicle_local_position`<br>`vehicle_global_position` | `estimator_attitude`<br>`estimator_local_position`<br>`estimator_global_position` |
| **实例数量** | 1个 | N个 (IMU数 × MAG数) |
| **工作队列** | wq:INS0 | wq:INS0, wq:INS1, wq:INS2, ... |
| **选择器** | 无（Sensors模块选择） | EKF2Selector |

### 6.2 订阅主题的差异

**文件**: `src/modules/ekf2/EKF2.cpp`

**第482-492行**: 回调注册（决定订阅哪个主题）
```cpp
if (!_callback_registered) {
#if defined(CONFIG_EKF2_MULTI_INSTANCE)

    if (_multi_mode) {
        // 多实例模式：订阅 vehicle_imu
        _callback_registered = _vehicle_imu_sub.registerCallback();

    } else
#endif // CONFIG_EKF2_MULTI_INSTANCE
    {
        // 单实例模式：订阅 sensor_combined
        _callback_registered = _sensor_combined_sub.registerCallback();
    }

    if (!_callback_registered) {
        ScheduleDelayed(10_ms);
        return;
    }
}
```

### 6.3 数据读取的差异

**单实例模式**（第672-717行）：
```cpp
else {  // 单实例模式

    }
}
```

## 11. 多实例模式的优势与代价

### 11.1 优势

#### 优势1: 估计器级冗余
```
单实例模式：传感器故障 → Sensors切换传感器 → EKF继续工作
          (切换可能导致瞬时扰动)

多实例模式：传感器故障 → 对应EKF2质量下降 → EKF2Selector切换到其他EKF
          (切换更平滑，因为其他EKF一直在运行)
```

#### 优势2: 更快的故障检测
- 每个EKF2独立评估其传感器质量
- EKF2Selector可以交叉验证多个估计结果
- 可以使用中值选择策略（≥3个实例时）

#### 优势3: 更高的可靠性
- 即使一个EKF2完全失效，其他实例仍正常工作
- 故障隔离更彻底

### 11.2 代价

#### 代价1: CPU负载增加
```
单实例: 1个EKF2 × 250Hz = 250次/秒 EKF更新
多实例: 2个EKF2 × 250Hz = 500次/秒 EKF更新 (双倍CPU)
```

**文件**: `src/modules/ekf2/EKF/ekf.cpp`

每次EKF更新包括：
- 协方差预测（24×24矩阵运算）
- 状态预测（向量运算）
- 观测融合（卡尔曼更新）
- 输出修正

**估算**：
- 单实例模式：~2-3% CPU使用率
- 双实例模式：~4-6% CPU使用率
- 四实例模式：~8-12% CPU使用率

#### 代价2: 内存占用增加
```
单实例: ~100 KB (EKF状态 + 缓冲区)
多实例: N × 100 KB + EKF2Selector (~50 KB)
```

#### 代价3: 启动时间增加
- 需要等待所有vehicle_imu和magnetometer主题advertised
- 多实例模式启动时间：~2-5秒
- 单实例模式启动时间：~1-2秒

### 11.3 选择建议

**使用单实例模式的场景**：
- ✅ CPU资源有限
- ✅ 传感器质量可靠
- ✅ 普通多旋翼应用
- ✅ 双IMU配置（如MicoAir H743默认）

**使用多实例模式的场景**：
- ✅ 高可靠性要求（载人、工业应用）
- ✅ CPU资源充足（F7/H7高性能MCU）
- ✅ 3个以上IMU（可使用中值选择）
- ✅ 需要估计器级故障检测
- ✅ 极端环境（强振动、电磁干扰）

## 13. EKF2Selector的选择算法

### 13.1 质量评分机制

**文件**: `src/modules/ekf2/EKF2Selector.cpp`

EKF2Selector为每个EKF2实例计算质量分数，基于：

1. **姿态有效性**
   - 姿态是否收敛
   - 姿态方差是否合理

2. **位置有效性**
   - 水平位置是否有效
   - 垂直位置是否有效

3. **新息一致性**（Innovation Consistency）
   - 速度新息测试比率
   - 位置新息测试比率
   - 航向新息测试比率

4. **故障状态**
   - 是否有滤波器故障
   - 是否有传感器故障

5. **输出跟踪误差**
   - 输出预测器与EKF状态的偏差

**选择逻辑**：
```cpp
// 伪代码
for (int i = 0; i < num_instances; i++) {
    score[i] = 0;

    if (attitude_valid[i]) score[i] += 100;
    if (local_position_valid[i]) score[i] += 100;

    score[i] -= vel_test_ratio[i] * 10;
    score[i] -= pos_test_ratio[i] * 10;

    if (fault_status[i] != 0) score[i] -= 1000;
}

selected_instance = argmax(score);
```

### 13.2 平滑切换机制

EKF2Selector不会频繁切换，采用滞后策略：
- 当前选中的实例需要明显劣于其他实例才会切换
- 切换时计算状态差异，平滑过渡
- 重置计数器同步

## 15. 常见问题

### 15.1 为什么MicoAir H743有双IMU但默认用单实例？

**原因**：
1. **CPU负载考虑**
   - 单实例模式CPU占用更低
   - 为控制回路留出更多资源

2. **简化调试**
   - 单实例模式更简单直观
   - 日志文件更小

3. **足够的冗余**
   - VotedSensorsUpdate已提供传感器级冗余
   - 对于普通应用已足够可靠

4. **兼容性**
   - 大多数PX4飞控默认使用单实例
   - 避免混淆

### 15.2 单实例模式下，备用IMU有什么用？

**作用**：
1. **自动故障切换**
   ```
   BMI088正常 → VotedSensorsUpdate选择BMI088
   BMI088故障 → VotedSensorsUpdate自动切换到BMI270
   ```

2. **数据质量监控**
   - 比较两个IMU的数据一致性
   - 检测传感器漂移

3. **热备份**
   - 备用IMU始终在采集数据
   - 切换无延迟

**文件**: `src/modules/sensors/voted_sensors_update.cpp`

**第220-222行**: 故障切换
```cpp
// 使用投票算法选择最优传感器
checkFailover(_accel, "Accel", events::px4::enums::sensor_type_t::accel);
checkFailover(_gyro, "Gyro", events::px4::enums::sensor_type_t::gyro);
```

### 15.3 什么时候应该使用多实例模式？

**推荐使用多实例模式的场景**：
- ✅ 载人飞行器
- ✅ 工业巡检（高价值任务）
- ✅ 长航时任务（减少单点故障）
- ✅ 强电磁干扰环境
- ✅ 高振动环境
- ✅ 需要飞行数据分析（可对比多个EKF估计）

**不推荐使用多实例模式的场景**：
- ❌ CPU资源受限的飞控（F4及以下）
- ❌ 只有1-2个IMU的系统
- ❌ 娱乐/测试用途
- ❌ 对电池续航时间敏感（CPU高负载增加功耗）

## 16. multi_init 函数详解

### 16.1 多实例初始化

```cpp
#if defined(CONFIG_EKF2_MULTI_INSTANCE)
bool EKF2::multi_init(int imu, int mag)
{
    // 更改订阅的实例索引
    bool changed_instance = _vehicle_imu_sub.ChangeInstance(imu);

#if defined(CONFIG_EKF2_MAGNETOMETER)
    if (!_magnetometer_sub.ChangeInstance(mag)) {
        changed_instance = false;
    }
#endif

    const int status_instance = _estimator_states_pub.get_instance();

    // 确保所有发布主题的实例编号一致
    if ((status_instance >= 0) && changed_instance
        && (_attitude_pub.get_instance() == status_instance)
        && (_local_position_pub.get_instance() == status_instance)
        && (_global_position_pub.get_instance() == status_instance)) {

        _instance = status_instance;  // 设置实例编号

        ScheduleNow();
        return true;
    }

    PX4_ERR("publication instance problem: %d att: %d lpos: %d gpos: %d",
            status_instance, ...);

    return false;
}
#endif
```

1. 切换`vehicle_imu`订阅到指定实例

3. 确保所有发布主题的实例编号一致
