## 三、EKF2 的订阅和发布关系（修正）

## 四、EKF2Selector 的作用

### 4.1 EKF2Selector 的数据流

EKF2Selector 订阅多个 EKF2 实例的输出，选择最优的实例，然后发布系统级主题：

```
EKF2 Instance 0 → estimator_attitude
EKF2 Instance 1 → estimator_attitude
EKF2 Instance 2 → estimator_attitude
        ↓
EKF2Selector (选择最优)
        ↓
vehicle_attitude (系统级主题)
vehicle_local_position (系统级主题)
vehicle_global_position (系统级主题)
vehicle_odometry (系统级主题)
```

## 六、关键要点总结

1. **VehicleIMU 订阅 `sensor_gyro` 和 `sensor_accel`**，不是 FIFO 版本
2. **Sensors 类创建 VehicleIMU 实例**，并订阅它们发布的 `vehicle_imu`
3. **VotedSensorsUpdate** 从 `vehicle_imu` 中提取数据，通过投票选择最优传感器
4. **Sensors 类发布 `sensor_combined`**，包含投票后的最优传感器数据
5. **EKF2 有两种模式**：
   - 多实例模式：订阅 `vehicle_imu`
   - 单实例模式：订阅 `sensor_combined`
6. **EKF2 发布大量主题**，包括姿态、位置、速度、偏差估计等
7. **EKF2Selector** 在多实例模式下选择最优 EKF2 实例的输出

## 七、VehicleAngularVelocity 的订阅关系

VehicleAngularVelocity **订阅的是 `sensor_gyro_fifo`**，用于高频率的角速度滤波处理，这是正确的。

```
sensor_gyro_fifo (BMI270/BMI088发布)
    ↓ VehicleAngularVelocity订阅
VehicleAngularVelocity (滤波处理)
    ↓ 发布
vehicle_angular_velocity
    ↓ MulticopterRateControl订阅
```

这与 VehicleIMU 的数据流是并行的，两者服务于不同的目的：
- **VehicleIMU**: 积分处理用于状态估计
- **VehicleAngularVelocity**: 滤波处理用于实时控制
